Fluxo do jogo

O jogo começa com os dois jogadores no setor central, [3,3], que é o único setor visitado no início. Por isso, só as portas dele aparecem na tela. A classe Principal repete ciclos até que o jogo termine, e cada ciclo tem três etapas: o turno do P1, o turno do P2 e o turno dos inimigos. Cada jogador faz duas ações no seu turno. Depois, cada inimigo vivo ataca uma vez cada jogador que está no mesmo setor que ele.

No turno de um jogador, a classe Turno desenha a tela com Graficos.imprimirJogo(), mostra o menu e lê a opção digitada. As ações possíveis são atacar, procurar e movimentar. O P2 também pode recuperar defesa. Antes de executar uma ação, o Turno verifica se ela é permitida. Quando não é, o motivo aparece na tela e a ação não é contada. Isso acontece quando o jogador digita uma opção que não existe, tenta atacar sem inimigos no setor, tenta procurar em um setor privado, tenta sair de um setor que ainda tem inimigos vivos ou escolhe uma direção sem porta. O P2 também não consegue recuperar a defesa do P1 se os dois estiverem em setores diferentes.

Movimentar e recuperar contam como uma ação cada, assim como atacar e procurar. Depois de cada ataque ou procura, o Turno retira do setor os inimigos com DEF menor ou igual a zero. Quando um jogador entra em um setor ainda não visitado, as portas desse setor passam a aparecer e são gerados de 1 a 3 inimigos.

O jogo termina quando um jogador entra no setor da fonte de infecção (X), e esse jogador vence. Também termina, com derrota, quando os 25 ciclos acabam ou quando os dois jogadores chegam a DEF menor ou igual a zero. Um jogador eliminado deixa de jogar e some do tabuleiro.

A classe Graficos só lê o estado do jogo pelos métodos get e nunca altera o tabuleiro, os jogadores ou os inimigos. Internamente, as posições vão de 0 a 4. Só a tela converte para a numeração de 1 a 5 usada no enunciado. Ao lado do tabuleiro aparece um painel com o setor de cada jogador. Se os dois estiverem no mesmo setor, o painel é um só; se estiverem em setores diferentes, aparecem dois painéis lado a lado.

O mesmo método, turnoJogador(Jogador jogador), atende o P1 e o P2. Isso é polimorfismo de inclusão (subtipo): o parâmetro é do tipo Jogador, mas também aceita um JogadorSuporte, e a chamada jogador.atacar(...) executa o método do tipo real do objeto. No trecho abaixo, a ação só é contada quando foi realizada:

if (this.executarAcao(jogador, opcao)) {
    acoes++;
}

Como executar

É preciso ter o JDK 17 ou mais recente, porque o código usa Random.nextInt(origem, limite). Na pasta do projeto, compile e execute com:

javac *.java
java Principal

Durante o jogo, digite 1 para atacar, 2 para procurar, 3 para movimentar (e depois N, S, L ou O para a direção) e 4 para recuperar defesa, opção que só aparece para o P2. Para atacar, digite o número do inimigo mostrado na lista.
